# P3 — Publish freely, stay in control

[Français](README.md) · [Download](https://github.com/portix1/P3/releases/latest) · [Beta testing (French)](BETA-TESTING.md)

P3 is a free, open-source, modular PHP content management system for self-hosted websites. It separates writing, day-to-day administration and site configuration. Authors do not need programming skills.

See a live website powered by P3: [Univers Guitare](https://www.universguitare.be/).

## Requirements

PHP 8.2 or later, PDO SQLite, mbstring, DOM, GD with WebP, fileinfo and zip. Signed updates also require PHP OpenSSL and a trusted public key. See the [French README](README.md) for distribution, verification and maintenance instructions.

## Help test P3

We welcome feedback from beginners and experienced webmasters before version 1.0. Use a separate test installation with disposable data. Report reproducible problems through [Issues](https://github.com/portix1/P3/issues/new/choose). Never post credentials, private data or exploit details publicly.
